# GitaMarathiTWA — Claude Context

## What this project is

An Android **Trusted Web Activity (TWA)** that wraps the Bhagavad Gita (Marathi / Dnyaneshwari) PWA hosted on GitHub Pages. The app has no custom Java/Kotlin code — it is a shell that launches a web app inside Chrome with no browser UI.

- **App name:** गीता-ज्ञानेश्वरी
- **Package ID:** `io.github.viveksovani.gitamarathi`
- **PWA URL:** `https://vivek-sovani.github.io/BhagvadgitaMarathi/`
- **Generated by:** `bubblewrap-cli`

## Key facts

- **No custom activity code** — uses `com.google.androidbrowserhelper.trusted.LauncherActivity` directly
- **Dependencies:** `androidbrowserhelper:2.5.0`, `appcompat:1.6.1`
- **Signing:** keystore at `./android.keystore`, alias `gitamarathi`
- **Fallback:** Chrome Custom Tabs if TWA verification fails (`fallbackType: customtabs`)
- **DAL verification host:** `vivek-sovani.github.io` — `assetlinks.json` must list the app's SHA-256 fingerprint
- **Gradle version:** 8.6
- **Java compatibility:** VERSION_17

## Build commands

```bash
./gradlew assembleDebug        # debug APK
./gradlew assembleRelease      # release APK
./gradlew bundleRelease        # release AAB (for Play Store)
```

## Regenerate Android files from bubblewrap

```bash
npm install -g @bubblewrap/cli
bubblewrap build
```

## Important files to edit for common tasks

| Task | File |
|---|---|
| Change PWA URL or host | `twa-manifest.json` → `host`, `startUrl`, `fullScopeUrl` then re-run bubblewrap |
| Change app version | `app/build.gradle` → `versionCode`, `versionName` |
| Change theme colors | `app/src/main/res/values/colors.xml` |
| Change app name | `app/src/main/res/values/strings.xml` |
| Update signing config | `app/build.gradle` → `signingConfigs.release` |
